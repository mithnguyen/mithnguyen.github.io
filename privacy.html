Privacy Policy

Last updated: 9 November 2026

This policy covers Mith Tools, private tools operated by their owner (contact below) for the owner's own websites.

Data the tools access

With the owner's consent, the tools use the Google Drive permission drive.file. This lets them create, read, update and delete only the files and folders that the tools themselves created in the owner's Google Drive (backup copies of the owner's websites and code). They cannot see any other file.

How the data is used

  • To upload backup copies, check that they were stored correctly, delete expired copies, and download them again for a restore.
  • Nothing else. The data is not sold, not shared with anyone, not used for advertising, and not used to train AI or machine learning models.

Storage and security

The Google access token is stored only on the owner's own servers, in a file readable by the administrator account. Backup files stay in the owner's Google Drive. Data travels between the servers and Google over encrypted connections (HTTPS).

Limited Use

Mith Tools' use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions. Files already created stay in the Drive until the owner deletes them.

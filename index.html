Mith Tools

Private automation tools for website backup and maintenance.

Mith Tools is a small set of command-line tools run by its owner on servers the owner manages. It is not a public service: there is no sign-up, and only the owner's own Google account is connected.

What it does

  • Website backup. Every night the backup tool packs a website's database, code and media files and uploads them to a folder in the owner's own Google Drive. It keeps 30 daily and 12 monthly copies, deletes older copies it created itself, and can restore a website from those copies.
  • Source code backup. It copies the owner's git repositories to the same Google Drive folder, so code survives an outage or an accidental deletion on the git host.

Google account access

The tools ask Google for the narrowest Drive permission, drive.file: they can see and change only the files and folders they created themselves. They cannot read any other file in the Drive.
